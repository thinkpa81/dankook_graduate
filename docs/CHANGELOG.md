# 변경 이력

## 2026-08-19
- 논문 목록의 연도 배지를 조회수로 교체하고 상세 열람마다 조회수가 원자적으로 1씩 증가하도록 개선
- 학과 내규의 장식용 이모지를 장 번호 중심 구성으로 교체하고 논문·공지사항의 파일 이모지를 표준 선형 아이콘으로 통일
- 헤더 학과명 아래에 `AIMS Lab(에임즈 랩) : AI, Innovation, Metaverse & Service Lab` 표기 추가
- 학과 소개 설명의 마지막 문장을 줄바꿈하고 지도교수 연구관심분야를 데스크톱·태블릿 3열로 고정
- 메인 히어로 영문 표기를 `DATA SCIENCE`로 간결화

## 2026-08-18
- 논문 분류를 `학술대회`와 `저널` 두 항목으로 통합하고 기존 국내·해외·본 심사 자료가 새 분류에 자동으로 모이도록 호환 처리
- 논문 등록·수정 입력 항목을 논문 제목, 저자, 사이트 주소로 단순화하고 URL 형식 검증 추가
- 학과 소개 상단 이미지 바로 아래에 지도교수 영역을 먼저 배치하고, 기존 학과 개요·전공 소개·교과과정이 뒤따르도록 순서 변경
- 서응교 지도교수 연구관심분야를 M&A·PMI, e-business 인터페이스, CMC, IT management, Design thinking, CSCL, MOOC 등 10개 항목으로 확장
- 학과 소개 페이지 지도교수 영역을 사진·교수 정보 2열 카드로 개편
- 서응교 지도교수 사진, 연구관심분야(Artificial Intelligence, Metaverse, Smart City), 이메일 링크 추가
- 학과 소개, 공지사항, 학과 내규, 논문, 인재풀 등록 페이지의 상단 배경을 사용자 제공 단국대학교 이미지로 순차 교체
- 5개 페이지가 동일한 높이·타이포그래피·오버레이·반응형 크롭 규칙을 공유하도록 `PageHero` 컴포넌트 추가
- 이미지별 피사체 위치에 맞춰 `object-position`을 조정하고 짙은 Navy 오버레이로 텍스트 명암비 확보
- 원본 PNG를 웹용 JPEG로 최적화해 배경 이미지 총 용량을 약 8.8MB에서 약 0.9MB로 축소
