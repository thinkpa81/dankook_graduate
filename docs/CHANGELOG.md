- 학과 내규의 장식용 이모지를 장 번호 중심 구성으로 교체하고 논문·공지사항의 파일 이모지를 표준 선형 아이콘으로 통일

- 학과 소개 설명의 마지막 문장을 줄바꿈하고 지도교수 연구관심분야 10개 항목을 정리
