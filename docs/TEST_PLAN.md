# 테스트 계획

## 정적 검사
- `npm run check`: TypeScript 오류가 없어야 한다.
- `npm run test:security`: 비밀번호 해시, 401/403 미들웨어, 동일 출처, 속도 제한, 공개 콘텐츠 라우트 정책, 논문 댓글 API 종료, 모집요강 정렬과 모집요강·공지·논문의 생성→수정→삭제 회귀 검사가 통과해야 한다. 실제 Express HTTP 통합 검사는 메모리 저장소만 사용해 운영 데이터를 변경하지 않는다.
- `npm run build`: 클라이언트와 서버 프로덕션 번들이 생성되어야 한다.
- `npm audit --omit=dev --audit-level=high`: 운영 의존성의 고위험 취약점이 없어야 한다.

## 홈페이지 기능
- 단국대학교 로고를 누르면 `/`로 이동한다.
- “학과 소개 보기”는 `/about`으로 이동한다.
- “입학안내”와 “모집요강”은 `/admissions/guidelines`로 이동한다.
- 최신 공지 목록과 “전체보기”가 공지 라우트로 연결된다.
- 자료실 외부 링크는 새 탭으로 열리고 `noopener noreferrer`를 사용한다.
- 관리자 로그인·로그아웃·관리자 메뉴가 노출되지 않고 공개 회원가입 UI도 없어야 한다.
- 논문 하위 메뉴와 모바일 메뉴가 동작한다.

## 반응형·시각 검사
- 1440px: 교수·연구분야 왼쪽 약 2/3, 사전 컨택 오른쪽 약 1/3과 연구카드 4·4·2 배치, 모집요강 230px 서브메뉴를 확인한다.
- 1024px: 학과소개 2열 유지, 좁은 왼쪽 패널의 연구카드 2열 배치와 모집요강 목록·검색을 확인한다.
- 768px: 교수 프로필·연구영역 내부 2열과 사전 컨택 전체 폭 아래 배치, 연구카드 2열과 모바일 메뉴 전환을 확인한다.
- 375px: 프로필→연구카드 1열→컨택 안내, 검색 컨트롤 전체 폭, 제목·이메일 줄바꿈을 확인한다.
- 320px: `scrollWidth <= clientWidth`이고 가로 스크롤·텍스트 잘림·겹침이 없는지 추가 확인한다.
- 학과소개에는 `박사과정 합류 전 사전 컨택`과 최신 안내 문장, 교수 이메일 `eungkyosuh@dankook.ac.kr`가 정확한 `mailto:` 링크로 표시되어야 한다.
- 브라우저 콘솔에 오류가 없어야 한다.

## 공개 콘텐츠 편집
- 모집요강 목록에서 제목, 게시 기관, 날짜, 조회수와 선택적 첨부 링크를 확인한다.
- 전체·제목·내용·게시기관 검색 범위가 각각 올바르게 필터링되고, 검색어 공백 제거·한글·영문 대소문자·Enter 제출·결과 없음 상태가 동작해야 한다.
- 목록은 게시일 내림차순이며 같은 날짜는 번호 내림차순이어야 한다.
- 모집요강 제목을 열면 조회수가 서버에서 1 증가하고 갱신된 값이 표시되어야 한다.
- 비로그인 상태에서 공지·논문·모집요강 등록·수정·삭제 버튼이 노출되고 실제 API 쓰기가 성공해야 한다.
- 동일 출처가 아닌 쓰기 요청은 403, 과도한 공개 쓰기 요청은 429를 반환해야 한다.
- `/admin`은 모집요강으로 이동하고 활성 페이지·프로덕션 번들에 관리자 로그인 UI가 없어야 한다.
- 논문 목록·상세에 댓글 수, 댓글 내용과 `로그인 후 댓글 작성` 문구가 없어야 하고 논문 댓글 쓰기 API는 410을 반환해야 한다.
- 공개 회원가입·인재풀 API는 410을 반환하고 방문자 개인정보 입력 양식이 노출되지 않아야 한다.
- 모집요강·공지·논문 등록·수정 모달은 키보드로 제출할 수 있고, 아이콘 버튼은 최소 44×44px이어야 한다.
- 저장·삭제 요청 중에는 중복 실행과 모달 닫기가 차단되고, 공지 첨부 선택은 키보드로 접근 가능하며 5개·파일당 10MB 제한을 안내해야 한다.
