# 테스트 계획

## 정적 검사
- `npm run check`: TypeScript 오류가 없어야 한다.
- `npm run build`: 클라이언트와 서버 프로덕션 번들이 생성되어야 한다.

## 홈페이지 기능
- 단국대학교 로고를 누르면 `/`로 이동한다.
- “학과 소개 보기”는 `/about`으로 이동한다.
- “입학안내”와 “모집요강”은 `/admissions/guidelines`로 이동한다.
- 최신 공지 목록과 “전체보기”가 공지 라우트로 연결된다.
- 자료실 외부 링크는 새 탭으로 열리고 `noopener noreferrer`를 사용한다.
- 관리자 로그인 버튼이 로그인 모달을 열고 공개 회원가입 UI가 없어야 한다.
- 논문 하위 메뉴와 모바일 메뉴가 동작한다.

## 반응형·시각 검사
- 데스크톱 1440×1000: 헤더, 히어로, 2열 게시물, 6개 빠른 메뉴를 확인한다.
- 태블릿 768×1024: 메뉴 전환과 2열 콘텐츠 줄바꿈을 확인한다.
- 모바일 390×844: 제목 줄바꿈, 버튼 적층, 슬라이드 메뉴, 가로 스크롤 부재를 확인한다.
- 브라우저 콘솔에 오류가 없어야 한다.

## 입학안내·관리자
- 모집요강 목록에서 제목, 게시 기관, 날짜, 조회수와 선택적 첨부 링크를 확인한다.
- 모집요강 제목을 열면 조회수가 서버에서 1 증가하고 갱신된 값이 표시되어야 한다.
- 비관리자는 모집요강 등록·수정·삭제 버튼을 볼 수 없고 API 쓰기 요청은 401/403이어야 한다.
- 관리자는 모집요강과 공지·논문을 등록·수정·삭제할 수 있어야 한다.
- 활성 관리자가 없을 때 `/admin`에 최초 관리자 설정 화면이 표시되고, 서버 로그의 15분 유효 코드로 한 번만 설정되어야 한다.
- 관리자는 다른 관리자를 추가하고 비밀번호를 변경하거나 삭제할 수 있어야 한다.
- 현재 로그인한 계정과 마지막 활성 관리자 계정 삭제는 차단되어야 한다.
- 공개 회원가입·인재풀 API는 410을 반환하고 방문자 개인정보 입력 양식이 노출되지 않아야 한다.
- 관리자 목록 응답에는 비밀번호, 해시, 이메일이 포함되지 않아야 한다.

## 메타데이터·배포
- `og:image`와 `twitter:image`가 `/opengraph.jpg`를 가리킨다.
- 파비콘이 단국대학교 DKU 마크로 표시된다.
- 배포 후 공개 URL에서 새 메인 문구와 캠퍼스 이미지가 제공되어야 한다.
