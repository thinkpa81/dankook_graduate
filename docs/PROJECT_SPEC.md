# 단국대학교 데이터지식서비스공학과 홈페이지 프로젝트 명세

## 목적
단국대학교 일반대학원 데이터지식서비스공학과의 교육·연구 정체성을 명확히 전달하고, 공지·논문·학과 내규·입학안내·공유 자료로 빠르게 이동할 수 있는 반응형 공식 홈페이지를 운영한다.

## 핵심 사용자
- 입학 및 연구 분야를 탐색하는 예비 대학원생
- 공지, 논문, 내규, 자료를 확인하는 재학생과 연구자
- 모집요강과 박사과정 사전 컨택 절차를 확인하는 지원자
- 게시물과 관리자 계정을 관리하는 운영자

## 핵심 기능
- 학과 소개, 공지사항, 논문, 학과 내규, 입학안내·모집요강 라우트
- 공지·논문·모집요강 API 조회와 관리자 관리
- 세션 기반 관리자 로그인과 관리자 계정 관리
- 관리자 전용 검증된 파일 업로드
- Google Drive 공유 자료실 연결

## 홈페이지 요구사항
- 단국대학교 공식 로고와 죽전캠퍼스 이미지를 첫 화면에서 식별할 수 있어야 한다.
- 메인 메시지는 “데이터로 지식을 만들고, 미래를 설계합니다”를 사용한다.
- 첫 화면에 “학과 소개 보기”와 “입학안내” 행동 버튼을 제공한다.
- 최신 공지와 자료실을 동일한 위계의 2열 목록으로 제공한다.
- 학과 소개에는 별도 개인정보 입력 없이 이메일로 문의하는 박사과정 사전 컨택 절차를 제공한다.
- 입학안내에는 모집요강 목록, 검색, 조회수와 선택적 HTTPS 첨부 링크를 제공한다.
- 모바일 0–767px, 태블릿 768–1023px, 데스크톱 1024px 이상에서 탐색과 읽기가 가능해야 한다.

## 비기능 요구사항
- TypeScript 검사와 프로덕션 빌드를 통과해야 한다.
- 이미지에는 대체 텍스트를 제공하고 키보드 탐색이 가능해야 한다.
- 소셜 미리보기에는 Replit 자산을 사용하지 않고 단국대학교 브랜드 자산을 사용한다.
- 관리자 비밀번호는 평문 또는 하드코딩으로 저장하지 않고 서버에서 scrypt 해시로만 저장한다.
- 최초 관리자는 활성 관리자가 없을 때만 Render 로그의 15분 유효 일회성 코드로 설정할 수 있다.
- `SESSION_SECRET`을 별도 설정하지 않은 환경에서는 서버가 안전한 임시 난수를 생성하며, 재시작 시 세션이 만료될 수 있다.
